# deutsch-dshatrov-anki

Немецкая лексика из рукописного блокнота → колода Anki `Deutsch DShatrov`.

- `words.tsv` — словарь (источник правды): `deutsch`, `russisch`, `notiz`, `beispiel`, `tags`.
- `sync.py` — заливает `words.tsv` в Anki на компьютере через AnkiConnect и запускает синк с AnkiWeb (→ телефон).

## Синхронизация

1. Anki запущен, установлен add-on AnkiConnect (код `2055492159`).
2. `python3 sync.py` (`--dry-run` — только показать изменения, `--no-web-sync` — без синка с AnkiWeb).

Заметки сопоставляются по полю `Deutsch`: новые добавляются, изменённые обновляются с сохранением истории повторений. Удаления из файла в Anki не удаляются — скрипт только сообщает о них.

Каждая запись — одна карточка DE → RU.
